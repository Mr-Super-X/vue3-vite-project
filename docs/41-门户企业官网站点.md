## 1. 能力概述

`/home` 是项目的**对外门面**：黑白极简企业官网形态（「星澜科技」演示品牌），走 `portal` 布局（64px 白底极简顶栏 + 锚点导航，无侧栏），经 `ROUTE_WHITE_LIST` 公开访问（免登录）。2026-10-20 由「政务工作台首页」重构而来（git fbbfabd，38 文件删除 + 5 新组件）。

**技术形态**：纯静态展示页——无数据链路、无 store、无 API 依赖；全 SVG 素材（手绘线条示意图 + tabler 静态图标 + 内联 SVG 字标）；全站唯一动效为 Hero fade-up，支持 `prefers-reduced-motion` 降级。

## 3. 修改文案/导航的三处同步约束

**@trigger**：修改站点文案、导航项或区块顺序时，`config/site.ts` 是唯一内容源，但**锚点 id 有三处消费方**，漏一处即出现「导航点击不滚动」或「scroll-spy 高亮错位」：

| 消费方                                | 字段                             | 作用                       |
| ------------------------------------- | -------------------------------- | -------------------------- |
| `config/site.ts`                      | `navItems[].anchor` / 各区块数据 | 内容单源                   |
| `views/index.vue`                     | 各区块根元素的 `id="..."`        | 锚点滚动落点               |
| `PortalNav.vue`（经 `config/nav.ts`） | 渲染 `href="#..."`               | 导航点击 + scroll-spy 匹配 |

**scroll-spy 机制**（`PortalNav.vue` 实现）：`IntersectionObserver` 监听各区块，`rootMargin: '-64px 0px -70% 0px'`（顶部 64px = header 高度 `--portal-header-h`，区块顶边越过 header 下沿才算进入视口）；回调里按 `entry.isIntersecting` 把命中的区块 id 回写 `activeKey`。jsdom / 旧浏览器无 `IntersectionObserver` 时静默跳过 scroll-spy，降级为仅点击高亮（点击仍 `scrollIntoView` 平滑滚动）。激活态 = 黑色短下划线（16×2 `::after`，`var(--portal-ink)`）+ `font-weight: 600` + `aria-current="location"`。

## 4. 公开访问与白名单约定

- `/home` 的公开访问**唯一机制**是 `apps/portal/src/router/whitelist.ts` 的 `ROUTE_WHITE_LIST`（经 `createWhiteList('NotFound', homeRouteNames)` 派生，含 `'Home'`）——`meta.requiresAuth` 不被守卫读取（纯类型声明），改 meta 无效
- 新增其他公开门户页时：路由 `name` 加入白名单 + 组件内无需任何登录态处理
- 顶栏右侧「登录/用户」双态：模板判据是 `v-if="!userStore.profile"`（读 user store `profile`，无 profile 即未登录；挂载时 `fetchProfile({ silent: true })` 探测一次，admin 有登录态时切门户自动显示用户态）；未登录显示「登录」按钮——点击经 `redirectToAuthLogin(window.location.pathname)` **整页跳 apps/auth 统一登录**（带 redirect 回跳，portal app 自身无 `/login` 路由），已登录显示用户名下拉（复用 UserInfo 的 `@visible-change` caret 旋转范式）

## 5. 品牌与样式约定

- **黑白极简**：全站仅黑白灰 + 一个强调色（13 个 `--portal-*` CSS 变量，定义于 `portal-tokens.scss`，含 `--portal-header-h` 64px 顶栏高度与 `--portal-ink` 主文字色）
- **BEM 命名**：5 个 Site 组件均按 `createNamespace('site-xxx')` kebab-case（site-hero / site-features / site-stats / site-about / site-footer），示例已录入 docs/05 BEM 示例表
- **响应式**：特性网格用 CSS 容器查询（`container-type: inline-size` + `@container`）做窄容器降级——el-plus 栅格断点只认视口宽度，门户容器宽度 ≠ 视口宽度时必须用容器查询（见 docs/35 §4 同型方案）
