## 🔄 构建工作流

```
pnpm dev
   ↓
vite (dev server)
   ├── UnoCSS 插件（生成原子化 CSS）
   ├── AutoImport（自动导入 ref/computed 等）
   ├── Components（自动注册 Element Plus）
   ├── Mock（拦截 /api/* 请求）
   └── Vue/TS 热更新（HMR < 50ms）

pnpm build
   ↓
type-check (vue-tsc) → build-only (vite build) → dist/

pnpm test
   ↓
vitest run → jsdom 环境 → 25+ 测试用例
```

## ⚙️ 核心配置文件

### `vite.config.ts`

```ts
import { fileURLToPath, URL } from 'node:url'
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueJsx from '@vitejs/plugin-vue-jsx'
import vueDevTools from 'vite-plugin-vue-devtools'
import UnoCSS from 'unocss/vite'
import AutoImport from 'unplugin-auto-import/vite'
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'
import { viteMockServe } from 'vite-plugin-mock'

export default defineConfig({
  plugins: [
    vue(),
    vueJsx(),
    vueDevTools(),
    UnoCSS(),
    AutoImport({
      imports: ['vue', 'vue-router', 'pinia'],
      resolvers: [ElementPlusResolver()],
      dts: 'src/types/auto-imports.d.ts',
    }),
    Components({
      resolvers: [ElementPlusResolver()],
      dts: 'src/types/components.d.ts',
    }),
    // 仅在 dev/test 环境启用 mock（生产构建剔除）
    viteMockServe({
      mockPath: 'mock',
      enable: process.env.NODE_ENV !== 'production',
      watchFiles: true,
    }),
  ],
  resolve: {
    // src 下子目录别名（告别 ../../../utils/... 繁琐相对路径）
    // 与 tsconfig.app.json 的 paths 配置保持同步
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url)),
      '@api': fileURLToPath(new URL('./src/api', import.meta.url)),
      '@assets': fileURLToPath(new URL('./src/assets', import.meta.url)),
      '@components': fileURLToPath(new URL('./src/components', import.meta.url)),
      '@composables': fileURLToPath(new URL('./src/composables', import.meta.url)),
      '@directives': fileURLToPath(new URL('./src/directives', import.meta.url)),
      '@enums': fileURLToPath(new URL('./src/enums', import.meta.url)),
      '@layouts': fileURLToPath(new URL('./src/layouts', import.meta.url)),
      '@locales': fileURLToPath(new URL('./src/locales', import.meta.url)),
      '@modules': fileURLToPath(new URL('./src/modules', import.meta.url)),
      '@router': fileURLToPath(new URL('./src/router', import.meta.url)),
      '@store': fileURLToPath(new URL('./src/store', import.meta.url)),
      '@types': fileURLToPath(new URL('./src/types', import.meta.url)),
      '@utils': fileURLToPath(new URL('./src/utils', import.meta.url)),
    },
  },
  css: {
    preprocessorOptions: {
      scss: {},
      less: { javascriptEnabled: true },
    },
  },
  build: {
    target: 'es2022',
    sourcemap: false,
    chunkSizeWarningLimit: 1000,
    rollupOptions: {
      output: {
        // 手动拆分第三方库（vendor chunk）→ 利用浏览器强缓存
        // 业务代码 (src/) 变化时只更新业务 chunk，第三方库 chunk 命中缓存
        // 注：Vite 8 用 rolldown 替代 rollup，manualChunks 必须是函数（不能是对象）
        manualChunks(id) {
          if (!id.includes('node_modules')) return undefined
          // Vue 核心：vue / vue-router / pinia / @vue/*
          if (id.includes('/vue/') || id.includes('/pinia/') || id.includes('/@vue/')) {
            return 'vendor-vue'
          }
          // UI 库：element-plus / @element-plus/icons-vue / unplugin-vue-components
          if (id.includes('/element-plus/') || id.includes('/unplugin-vue-components/')) {
            return 'vendor-ui'
          }
          // 其他第三方库：axios / vue-i18n / 等
          return 'vendor-utils'
        },
      },
    },
  },
})
```

**关键插件**：

| 插件                       | 作用                                        |
| -------------------------- | ------------------------------------------- |
| `@vitejs/plugin-vue`       | Vue SFC 编译                                |
| `@vitejs/plugin-vue-jsx`   | JSX/TSX 支持                                |
| `vite-plugin-vue-devtools` | Vue DevTools 集成                           |
| `unocss/vite`              | 原子化 CSS                                  |
| `unplugin-auto-import`     | 自动导入（无需手动 import ref/computed 等） |
| `unplugin-vue-components`  | 自动注册组件（含 Element Plus）             |
| `vite-plugin-mock`         | 开发态 API Mock                             |

### 🆕 Vite 8 构建优化（别名 + Vendor Chunk）

#### 14 个子目录别名（告别相对路径）

`vite.config.ts` 的 `resolve.alias` + `tsconfig.app.json` 的 `paths` 同步配置：

| 别名           | 映射                  | 典型用途                      |
| -------------- | --------------------- | ----------------------------- |
| `@`            | `./src/*`             | 根别名（最灵活）              |
| `@api`         | `./src/api/*`         | 接口层（authApi、userApi 等） |
| `@components`  | `./src/components/*`  | 公共组件                      |
| `@composables` | `./src/composables/*` | 组合式函数（useRequest 等）   |
| `@directives`  | `./src/directives/*`  | 自定义指令（v-permission）    |
| `@enums`       | `./src/enums/*`       | 枚举常量                      |
| `@layouts`     | `./src/layouts/*`     | 页面布局                      |
| `@locales`     | `./src/locales/*`     | 国际化词条                    |
| `@modules`     | `./src/modules/*`     | 业务模块                      |
| `@router`      | `./src/router/*`      | 路由配置                      |
| `@store`       | `./src/store/*`       | Pinia store                   |
| `@types`       | `./src/types/*`       | 全局类型                      |
| `@utils`       | `./src/utils/*`       | 工具函数                      |
| `@assets`      | `./src/assets/*`      | 静态资源                      |

**使用对比**：

```ts
// 之前（相对路径）
import { useUserStore } from '../../../store/modules/user'
import { formatDate } from '../../../utils/format'

// 现在（短别名）
import { useUserStore } from '@store/modules/user'
import { formatDate } from '@utils/format'

// 或根别名（更灵活）
import { useUserStore } from '@/store/modules/user'
import { formatDate } from '@/utils/format'
```

#### Vendor Chunk 拆分（利用浏览器强缓存）

**设计目标**：第三方库代码稳定 → chunk 文件名带 hash 不变 → 浏览器长期缓存；业务代码改动时只更新业务 chunk，第三方库 chunk 命中缓存。

**3 个 vendor chunk 分组**：

| Chunk          | 大小 (gzip)         | 内容                                                             |
| -------------- | ------------------- | ---------------------------------------------------------------- |
| `vendor-vue`   | 5.9 KB / 2.8 KB     | vue / vue-router / pinia / @vue/*                                |
| `vendor-ui`    | 477.8 KB / 167.3 KB | element-plus / @element-plus/icons-vue / unplugin-vue-components |
| `vendor-utils` | 123.9 KB / 43.5 KB  | axios / vue-i18n / 其他第三方                                    |

**为什么是函数式 manualChunks（不是对象）**：

Vite 8 用 **rolldown** 替代 rollup 作为底层打包器，API 变化：

| API            | Rollup (Vite 4-6)                    | Rolldown (Vite 8)                           |
| -------------- | ------------------------------------ | ------------------------------------------- |
| `manualChunks` | 支持对象 `{ 'vendor-vue': ['vue'] }` | **只支持函数** `function(id) { ... }`       |
| 错误信息       | 友好提示                             | `TypeError: manualChunks is not a function` |

**匹配逻辑**（基于 `id.includes()`）：

```ts
manualChunks(id) {
  if (!id.includes('node_modules')) return undefined  // 业务代码不归 vendor
  if (id.includes('/vue/') || id.includes('/pinia/') || id.includes('/@vue/')) {
    return 'vendor-vue'
  }
  if (id.includes('/element-plus/') || id.includes('/unplugin-vue-components/')) {
    return 'vendor-ui'
  }
  return 'vendor-utils'  // 其他所有第三方
}
```

**缓存效益**：

| 场景              | 缓存策略                                                       |
| ----------------- | -------------------------------------------------------------- |
| 首次访问          | 下载所有 chunk（vendor-vue + vendor-ui + vendor-utils + 业务） |
| 升级 vue          | 只 `vendor-vue` hash 变，其他 vendor 命中缓存                  |
| 升级 element-plus | 只 `vendor-ui` hash 变                                         |
| 业务代码改动      | 只业务 chunk hash 变，3 个 vendor 全部缓存命中                 |
| 纯开发不升级      | 全部 304 Not Modified（极快）                                  |

**手动验证 3 种方法**（详见 `docs/01-工具兼容性问题踩坑记录.md`）：

```bash
# 方法 1: 浏览器 DevTools Network 标签（最直观）
pnpm dev
# F12 → Network → 刷新 → 筛选 JS chunk

# 方法 2: sourcemap 验证（最准确）
sed -i 's/sourcemap: false/sourcemap: true/' vite.config.ts
pnpm build
for f in dist/assets/vendor-*.js.map; do
  cat "$f" | grep -oE 'node_modules/[^"]+' | sort -u
done
sed -i 's/sourcemap: true/sourcemap: false/' vite.config.ts  # 还原

# 方法 3: 改源码对比 hash 变化（最直观感受缓存）
pnpm build 2>&1 | grep vendor  # 记录 hash
echo "--- 修改 src/App.vue 末尾加个空行 ---"
pnpm build 2>&1 | grep vendor  # 对比：业务 chunk 变 hash，vendor 不变
```

### `tsconfig.json`（TypeScript 6 strict 模式）

```json
{
  "files": [],
  "references": [
    { "path": "./tsconfig.node.json" },
    { "path": "./tsconfig.app.json" },
    { "path": "./tsconfig.vitest.json" }
  ]
}
```

### `tsconfig.app.json`（应用代码）

```json
{
  "extends": "@vue/tsconfig/tsconfig.dom.json",
  "include": ["env.d.ts", "src/**/*", "src/**/*.vue"],
  "exclude": ["src/**/__tests__/*"],
  "compilerOptions": {
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "noImplicitOverride": true,
    "paths": {
      "@/*": ["./src/*"]
    },
    "tsBuildInfoFile": "./node_modules/.tmp/tsconfig.app.tsbuildinfo"
  }
}
```

**strict 模式额外配置**：

| 选项                         | 作用                                      |
| ---------------------------- | ----------------------------------------- |
| `noUncheckedIndexedAccess`   | 数组/对象下标访问返回 `T \| undefined`    |
| `exactOptionalPropertyTypes` | 区分 `prop?: T` 和 `prop: T \| undefined` |
| `noImplicitOverride`         | 子类覆盖父类方法必须加 `override`         |

### `vitest.config.ts`

```ts
import { fileURLToPath } from 'node:url'
import { mergeConfig, defineConfig, configDefaults } from 'vitest/config'
import viteConfig from './vite.config'

export default mergeConfig(
  viteConfig as never,
  defineConfig({
    test: {
      environment: 'jsdom',
      exclude: [...configDefaults.exclude, 'e2e/**'],
      root: fileURLToPath(new URL('./', import.meta.url)),
      globals: true,
      server: {
        deps: {
          inline: ['element-plus', '@element-plus/icons-vue'],
        },
      },
      css: true,
      coverage: {
        provider: 'v8',
        reporter: ['text', 'html', 'lcov'],
        include: ['src/**/*.{ts,vue}'],
        exclude: ['src/**/__tests__/**', 'src/**/index.ts', 'src/main.ts', 'src/types/**'],
        thresholds: { lines: 70, functions: 70, branches: 60, statements: 70 },
      },
    },
  })
)
```

**关键点**：

- `server.deps.inline: ['element-plus']`：让 element-plus 在测试时不被外部化（解决 "Unknown file extension .css" 错误）
- `css: true`：让 vitest 处理 CSS 导入
- `coverage`：v8 provider + 70% 阈值（脚手架阶段宽松）

## 📦 状态管理架构

按 spec §5 模块边界铁律：

```
全局 store/modules/        业务模块 store/
├── app.ts (侧边栏/语言)  ├── modules/auth/store/
└── user.ts (token/权限)   ├── modules/user/store/
                           └── modules/dashboard/store/
```

**Pinia Setup Store 风格**（更接近 composables 心智）：

```ts
// src/store/modules/user.ts
export const useUserStore = defineStore('user', () => {
  const token = ref<string>(localStorage.getItem('token') ?? '')
  const profile = ref<UserProfile | null>(null)

  const isLoggedIn = computed(() => !!token.value)

  async function login(credentials: LoginPayload) { ... }
  async function fetchProfile() { ... }
  function logout() { ... }

  return { token, profile, isLoggedIn, login, fetchProfile, logout }
})
```

## 🐛 故障排查

### 1. `pnpm dev` 启动报 `IGNORED_BUILDS`

**症状**：`Ignored build scripts: @parcel/watcher, esbuild`

**解决**：`pnpm-workspace.yaml` 加 allowBuilds：

```yaml
allowBuilds:
  '@parcel/watcher': true
  esbuild: true
```

### 2. Vitest 报 `Unknown file extension ".css"`

**原因**：vitest 默认不处理 CSS 导入

**解决**：`vitest.config.ts` 加 `css: true` + `server.deps.inline: ['element-plus']`

### 3. Vue Router 报 `No match found for location`

**原因**：路由 path 配置错误或 404 fallback 未配置

**解决**：检查 `src/router/modules/*.ts` 的 path 配置，并在最后加 catch-all：

```ts
{ path: '/:pathMatch(.*)*', redirect: '/404' }
```

### 4. Pinia store 跨模块引用报错

**原因**：违反模块边界铁律（modules 间不互相 import 内部）

**解决**：模块间通信通过 `modules/<m>/index.ts` 暴露的对外接口

### 5. `vue-tsc --build` 报 "Cannot find type definition file"

**解决**：检查 `tsconfig.app.json` 的 `types` 字段是否包含 `vite/client` 和 `node`
