>

## 专节：package-contract 报错

`error 级` 的两类典型：

- **`undeclared`**：使用了某 npm 包但本 package.json 未声明 → 把该包加入 `dependencies`
  （apps/* 的运行时依赖）或对应 package 的 `dependencies`/`peerDependencies`（packages/*）
- **方向违例**：`packages/*` 反向依赖 apps 或下游包（如 shared → ui）→ 调整 import 方向，
  依赖铁律见 CLAUDE.md §2.1（config ∥ shared → mock → ui 单向）
