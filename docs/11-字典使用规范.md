# 字典使用规范

> **什么时候用字典 store**：业务字段值是后端控制、运行时可能变动、UI 需要展示中文标签（如用户状态 / 订单状态 / 角色类型）。
> **什么时候用 `src/enums/`**：字段值是编译期常量、前端代码分支判断用（如 HTTP status code、role enum 等系统字段）。

字典系统示例：用户状态（启用/禁用/锁定）、角色（管理员/普通用户）、订单状态（待支付/已支付等）。共同特征：值由后端定义，UI 用 `el-select / el-table` 展示成中文。

---

## 1. 三层架构速查

```
UI:    <el-select :options="options" />     <-- reactive（变化自动更新）
              ↓
Composable: useDict('user_status')          <-- 业务侧入口（lazy + 缓存）
              ↓
Store:  useDictStore.fetchDict()             <-- 5min 业务层缓存 + 30s 网络层缓存
              ↓
API:    dictApi.getByType()                  <-- request<T>() 走 14 个基建
              ↓
Mock:   /api/dict/user_status                <-- vite-plugin-mock 内置
```

| 层         | 文件                         | 何时接触                          |
| ---------- | ---------------------------- | --------------------------------- |
| API        | `src/api/modules/dict.ts`    | 添加新字典 URL（一般不需要动）    |
| Mock       | `mock/dict.ts`               | 后端没接口 / 纯前端演示时加假数据 |
| Store      | `src/store/modules/dict.ts`  | 调整 PRELOAD_DICT_KEYS 预加载列表 |
| Composable | `src/composables/useDict.ts` | 业务侧**只调这个**                |

## 2. 业务侧用法

### 2.1 el-select 用法（最常用）

```vue
<script setup lang="ts">
import { useDict } from '@/composables/useDict'
const { options, getLabel, refresh, loading } = useDict('user_status')
</script>

<template>
  <el-select v-model="form.status" :options="options" :loading="loading">
    <template v-for="opt in options" :key="opt.value" :value="opt.value">
      {{ opt.label }}
    </template>
  </el-select>
</template>
```

### 2.2 el-table 列翻译

```vue
<script setup lang="ts">
import { useDict } from '@/composables/useDict'
const { getLabel } = useDict('order_status')

const rows = [
  { id: 1, status: 'pending' },
  { id: 2, status: 'shipped' },
]
</script>

<template>
  <el-table :data="rows">
    <el-table-column label="状态">
      <template #default="{ row }">
        {{ getLabel(row.status) }}
      </template>
    </el-table-column>
  </el-table>
</template>
```

### 2.3 强制刷新（管理员改字典后）

```ts
const { refresh } = useDict('user_status')
async function onDictChanged() {
  await refresh() // 传 force=true，立即重发请求
}
```

## 3. 缓存策略

| 层                           | 时间     | 控制                                           | 失效时机        |
| ---------------------------- | -------- | ---------------------------------------------- | --------------- |
| **网络层**（http.ts 拦截器） | 30s TTL  | `cache: { ttl: 30 }` 在 API 配置里调           | 自动过期        |
| **业务层**（dict store）     | 5min TTL | `STORE_TTL_MS` 常量                            | 自动过期        |
| **业务层 + force**           | 立即刷新 | `fetchDict(type, true)` 或 `useDict.refresh()` | 调 refresh() 时 |

> **双层缓存的作用**：网络层防止并发请求（同一秒内多次访问只发 1 次请求）；业务层防止重复 await + 跨页面共享。
>
> **修改缓存时间**：
>
> - 网络层 TTL：改 `dict.ts` API 的 `cache.ttl`
> - 业务层 TTL：改 `dict.ts` 的 `STORE_TTL_MS`

## 4. 预加载 vs 按需加载

### 4.1 预加载（登录时自动拉）

**适用**：登录后立即需要的字典（如导航栏角色列表、首页用户状态筛选）。

修改 `src/store/modules/dict.ts` 的 `PRELOAD_DICT_KEYS`：

```ts
export const PRELOAD_DICT_KEYS: readonly string[] = [
  'user_status',
  'role',
  // 新增常用字典：
  // 'order_status',
  // 'product_category',
]
```

`src/store/modules/user.ts` 的 `login()` 已自动调用 `preloadDict()`，**业务无需手动触发**。

### 4.2 按需懒加载（默认）

**适用**：90% 的业务字典。`useDict('xxx')` 首次调用时自动拉取，5min 内复用缓存。

```ts
// 任意组件内调
const { options } = useDict('custom_dict')
```

### 4.3 两者组合（推荐）

- `PRELOAD_DICT_KEYS` 列**首页 / 导航 / 高频使用**的字典
- 业务模块的低频字典走按需加载

## 5. 后端协议与扩展字段

### 5.1 返回结构

```json
{
  "code": 200,
  "message": "ok",
  "data": [
    { "value": "active", "label": "启用" },
    { "value": "inactive", "label": "禁用" }
  ]
}
```

### 5.2 扩展字段

`DictEntry` 是 index-signature 类型，业务可加任意字段（如 `color` / `disabled`）：

```ts
{ value: 'shipped', label: '已发货', color: 'primary', disabled: false }
```

业务侧读：

```ts
const entry = options.value.find((o) => o.value === 'shipped')
if (entry?.color) console.log(entry.color)
```

## 6. 常见坑

| 症状                                    | 原因                                            | 解法                                                                    |
| --------------------------------------- | ----------------------------------------------- | ----------------------------------------------------------------------- |
| `getLabel('xxx')` 永远返回 `xxx` 字符串 | 字典未加载或 key 拼错                           | 先调 `useDict(key)` 触发加载，再 `await store.fetchDict(key)`           |
| `el-select` 选项空白                    | `options.value` 初始是 `[]`，fetchDict 还没完成 | 等 `loading === false` 后再渲染；或用 `v-if="options.length"` 兜底      |
| 后端改了字典 UI 没更新                  | 业务层 5min 缓存 + 网络层 30s 缓存              | 调 `refresh()` 强制刷新；或浏览器 DevTools 清 localStorage 强制重新登录 |
| 切换账号后看到的还是上个账号的字典      | user store logout 没清 dict cache               | 计划任务：logout 时调 `useDictStore().clear()`                          |
| 控制台 401 不停                         | token 过期 + mock 没 `/api/auth/refresh`        | 参考 docs/10 任务 4 问题 A                                              |
