## 🚀 推荐理由

### ⚡ 技术栈：永远追新，版本统一

- **前沿技术栈**：Vue 3.6（beta 精确钉版 3.6.0-beta.17）+ TypeScript 6 + Vite 8 + Pinia 3 + Element Plus 2.14 + UnoCSS 66 + pnpm 11.x，全部锁版本，杜绝"装完跑不起来"。
- **强类型兜底**：`vue-tsc` 强制全量类型校验，`strict` 模式 + `pnpm build` 内含各 app `type-check:full` 门禁（单 app 全量 `pnpm -C apps/<a> type-check:full`，根级无裸命令）。

### 🧱 Feature-Sliced 模块化：业务自治，零交叉

- **按业务切分**：`modules/<m>/` 一个目录就是一个完整模块（views / components / store / apis / routes），改一个模块集中一处、删一个模块 = 删一个目录。
- **依赖单向铁律**：`common/` / `directives/` / `plugins/` 绝不引用 `modules/`，模块间只能通过 `index.ts` 对外接口通信——技术栈可零侵入替换（Pinia→Redux、Element Plus→Ant Design Vue 都不动业务代码）。

### 🪄 一键脚手架：3 步加新模块

- **代码生成器**：`pnpm new-module <kebab-name>` 一键生成 6 个骨架文件，**路由自动注册**（`auto-register.ts` 用 `import.meta.glob` 扫描模块路由），无需在 app 的 `src/router/` 任何文件手动 import。
- **模块删除器**：`pnpm remove-module <name>` 一键清理（默认 dry-run + 二次确认）。

### 🛡️ 防御性 UI：异步组件三态零负担

- **三态封装**：`useRequest` composable + `<AsyncState>` 组件，**Loading / Error / Empty** 三个状态默认内置，每个异步组件 1 行模板即可完成——告别 return null 白屏。
- **全局错误兜底**：`plugins/errorHandler` 统一捕获组件错误 / window 错误 / Promise 拒绝，**Sentry 扩展点**已预留。

### 🌐 网络层：三件套全覆盖

- **流式请求**：原生支持 **SSE / NDJSON / auto** 三格式，`AbortController` 全局取消 + 401 自动 refresh token。
- **Zod 参数校验**：`requestValidated(schema)` 失败行为可定制，杜绝后端报400 才返。
- **缓存 / 合并 / 分页适配**：高频请求零侵入加速，列表分页统一协议。

### 🎨 XForm 低代码表单引擎：杀手锏特性

- **Schema 驱动**：JSON 配置即渲染，**支持嵌套表单 / 数组节点 / 反应式联动（reaction deps）**——业务侧零手写模板。
- **覆盖完整**：Transfer / Upload / Card / FormItem 等 20+ Element Plus 组件开箱即用，**强校验 + 防循环联动保护**（单批 50 次自动熔断）。

### 🎯 工程化全家桶：开发到发布全自动

- **代码质量**：ESLint 10 + Prettier 3.9 + Husky pre-commit + lint-staged。
- **提交发布**：Commitlint 规范中文提交 + `pnpm push` 一站式提交推送 + `pnpm release` 自动 bump + tag + CHANGELOG + push。
- **测试**：Vitest 4 + `@vue/test-utils` + jsdom，覆盖率报告 + UI 模式可调试。

### 🧩 组件级杀手锏（`packages/ui/src/components/`）

> 三目录分布：`common/`（ProDialog / ProDialogForm / RichTextEditor / BaseChart / AsyncState / ErrorBoundary / DictSelect / DictTag）、`ProTable/`（ProTable）、`form-schema/`（XForm）——均经 unplugin-vue-components 自动注册，模板直接用。

| 组件                     | 用途                              | 关键能力                                                                                                 |
| ------------------------ | --------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `ProTable` v3.4          | 配置驱动企业级表格                | 双引擎（element-plus / vxe-table）/ 虚拟滚动 10 万行 / 自动高度 / 状态保持 / 内置格式化器 / 列设置持久化 |
| `ProDialog` v1.1         | 高级弹窗（声明式 + 命令式双入口） | 拖拽 + 全屏 + resizable + **`resizeMinToInitial`**（最小尺寸锁定初始宽高）/ useDialog Promise 语义       |
| `ProDialogForm`          | 弹窗表单（命令式提交封装）        | 防重复提交 / reset-on-close / XForm schema 集成 / 命令式 useDialog 动态唤起                              |
| `XForm`                  | Schema 驱动表单引擎               | 嵌套表单 / 数组节点 / 反应式联动（reaction deps 单批 50 次熔断）/ 20+ EP 组件开箱即用                    |
| `RichTextEditor`         | 富文本编辑器封装                  | WangEditor V5 + XSS 双向 sanitize + 命令式 API（`editorRef.setHtml/getHtml/destroy`）                    |
| `BaseChart`              | ECharts 包装                      | SSR-safe / loading + empty 三态 / 主题自适应                                                             |
| `AsyncState`             | 异步三态展示组件                  | Loading / Error / Empty 一体化，支持 @retry 重试                                                         |
| `ErrorBoundary`          | 组件错误兜底                      | Vue `onErrorCaptured` + 上报钩子                                                                         |
| `DictSelect` / `DictTag` | 字典快捷组件                      | 自动接入 `useDict`（v2 多 code 契约形态）/ ElTag 类型自动映射                                            |

> **Composable 一行 API**：`useAppRouter`（路由跳转 / back / 参数）/ `useRequest`（三态 + 取消）/ `useAuth`（AND / ANY 权限）/ `useDict`（多字典契约）/ `useDialog` / `useConfirm`（取消 resolve false）/ `useTheme`（主题 + 持久化）/ `useLogout`（清全部缓存 + 跳登录）。各 composable 归属与选型见 [docs/18-代码组织决策表](./18-代码组织决策表.md) §2。

### 🖥️📱 多端布局一套代码（v2.x 核心增量）

同一套 Feature-Sliced 代码库，按路由挂不同 layout 即覆盖四种终端形态——无需为 H5 / 大屏另起项目：

| 终端形态        | layout    | 适配机制                                            | 文档                                                                            |
| --------------- | --------- | --------------------------------------------------- | ------------------------------------------------------------------------------- |
| 中后台管理      | `default` | 经典侧边栏 + 响应式断点                             | [docs/07](./07-路由模块设计.md)                                                 |
| 企业门户        | `portal`  | 顶部水平导航                                        | [docs/07](./07-路由模块设计.md)                                                 |
| H5 移动端       | `h5`      | viewport rem（运行时）+ postcss-pxtorem（编译时）   | [docs/34](./34-H5布局与rem适配.md)、[ADR 37](./37-h5-rem适配决策记录.md)        |
| 数据大屏/拼接屏 | `big`     | transform: scale 容器等比缩放（不改 html fontSize） | [docs/35](./35-大屏布局与scale适配.md)、[ADR 38](./38-big-scale适配决策记录.md) |

- 设计稿尺寸经路由 `meta` 声明（h5 走 rem 基准、big 走 `meta.bigScreen`），同一 layout 内多尺寸页面共存
- 各 layout **自包含**（components/config/images/styles 内聚），互不引用，可按需整体删除

### 📊 可观测与性能：生产级基线

- **Web Vitals**：自动采集 LCP / INP / CLS / TTFB，4 种上报端点接入示例齐全。
- **包体积分析**：`pnpm analyze` 输出 `dist/stats.html`，CI 阶段对比防止体积膨胀。
- **路由一致性校验**：`pnpm check:routes` 在 CI 强制 5 项一致性，杜绝路由漂移。

### 🌓 主题与国际化：开箱即用

- **双主题**：浅色 / 深色 / 跟随系统三态切换，`useTheme().toggleMode()` 一行 API + Pinia 持久化。
- **BEM 命名空间**：`vv-` 默认前缀（环境变量可改），运行时工具 + SCSS mixin 双轨制，CSS 隔离不再靠 `scoped`。
- **i18n**：vue-i18n 11 + 中英文双语，`useAppStore().setLocale()` 切换。

### 🚀 极速上手：30 分钟完成第一次提交

- **零后端依赖**：内置 `vite-plugin-mock`。登录是跨应用链路（apps/auth）；新人首跑 `pnpm -C apps/admin dev` + `VITE_DEMO_NO_AUTH=true` 免登录直达，或 `pnpm dev:gateway` 走 :8080 完整登录链路（默认账号 **admin / 123456**，登录后自动回跳）。
- **本地模式**：`pnpm dev:local` 切到本地菜单模式，**完全无后端**即可联调完整业务流程。
- **新手指引**：`docs/10-新手指引.md` 设计 5 个任务，30 分钟从 clone 到加新模块。

### 📚 文档即交付：48 份编号文档

- **覆盖完整**：架构 / 路由 / 状态 / BEM / 主题 / i18n / Token / 流式请求 / Zod / XForm / useRequest 等全部配套规范。
- **架构评估**：`docs/audit/` 周期性评估报告，DX 改进有迹可循。
- **归档可溯**：`docs/archive/2026-07/` 历史设计与计划按月归档，时间线清晰。
