## 1. v-copy —— 文本复制

> **首次文档化**：v1.0.0 / 2026-09-17（之前完全未文档化，本指南补齐）

### 1.1 用法

```vue
<template>
  <!-- 字符串值：点击复制固定文本 -->
  <button v-copy="'订单号：SO-2026-0917-001'">复制订单号</button>

  <!-- 函数值：点击时实时调用，避免闭包陈旧（依赖响应式状态时尤其重要） -->
  <span v-copy="() => `订单号：${order.id}`"></span>

  <!-- 无修饰符；空内容时 ElMessage.warning 提示 -->
  <div v-copy="">点我没东西可复制</div>
</template>
```

### 1.2 行为矩阵

| 场景               | 检测 / 行为                                                |
| ------------------ | ---------------------------------------------------------- |
| 字符串值（绑定后） | click 读 `binding.value` 复制                              |
| 函数值             | click 时**实时调用函数**取得当前值（避免闭包陈旧）         |
| 值变化             | `updated` 钩子替换 `ctx.binding` 引用，下次 click 读到新值 |
| 复制成功           | `ElMessage.success('复制成功')`                            |
| 复制失败           | `ElMessage.error('复制失败，请手动复制')`                  |
| 内容为空           | `ElMessage.warning('复制内容为空')`（不调用复制 API）      |

### 1.3 实现要点

- **现代 API 优先**：`navigator.clipboard.writeText`（HTTPS / localhost / file: 等 secure context）
- **自动降级**：`document.execCommand('copy')` 兼容 HTTP 部署站点 / 旧浏览器
- **双层兜底**：现代 API 调用失败时再次降级到 execCommand
- **WeakMap 存 ctx**：与 draggable 范式一致，元素 GC 时自动释放，无内存泄漏
- **默认指针光标**：`mounted` 时给宿主元素加 `pointer`，提示可点击
- **完整清理**：`unmounted` 移除 click 监听 + WeakMap.delete，防止组件频繁挂/卸载时残留监听器

### 1.4 典型场景

| 场景                 | 实现                                                  |
| -------------------- | ----------------------------------------------------- |
| 订单号复制           | `<span v-copy="() => `订单号：${order.id}`">`         |
| Token / API Key 复制 | `<el-button v-copy="apiKey">复制 API Key</el-button>` |
| URL 分享             | `<a v-copy="shareUrl">复制链接</a>`                   |
| 动态生成的 markdown  | `<pre v-copy="() => generateMarkdown(data)" />`       |

### 1.5 已知限制

- **仅鼠标事件**：中后台桌面端场景；平板触摸需改 Pointer Events
- **HTTPS 要求**：secure context 缺失时自动降级到 execCommand（仍可工作但浏览器可能弹权限警告）
- **剪贴板权限**：用户首次拒绝授权后，现代 API 永远失败（降级到 execCommand 也可能在某些浏览器失败）

### 1.6 测试覆盖

`src/directives/copy.spec.ts`（实现完整，未文档化待跟进）覆盖：

- 字符串 / 函数值复制
- secure context 切换（mock）
- 成功 / 失败 / 空内容三种 ElMessage 分支
- updated 钩子替换 binding
- unmounted 清理

## 2. 防抖指令

### 2.1 v-inputDebounce

```vue
<el-input v-model="query" v-inputDebounce:300="onSearch" />
```

| 参数                | 默认值 | 说明                                 |
| ------------------- | ------ | ------------------------------------ |
| `value` (binding)   | —      | input 事件回调函数                   |
| `arg`（冒号后数字） | `300`  | 防抖延迟（ms），如 `:500` 表示 500ms |

**应用场景**：搜索框 input（避免每按一键发一次请求）。

### 2.2 v-buttonDebounce

```vue
<el-button v-buttonDebounce:500="handleSubmit">提交</el-button>
```

| 参数                | 默认值 | 说明           |
| ------------------- | ------ | -------------- |
| `value` (binding)   | —      | click 回调函数 |
| `arg`（冒号后数字） | `500`  | 防抖延迟（ms） |

**应用场景**：防止快速重复点击提交按钮（如表单提交）。

## 3. 权限指令

详见 [`docs/23-权限设计.md`](23-权限设计.md)（已含 v-permission / v-auth 完整语义）。

### 3.1 速查

```vue
<!-- 整页权限 -->
<div v-permission="['user:edit']">
  <UserForm />
</div>

<!-- 按钮级 AND 语义（用户拥有全部权限才显示） -->
<el-button v-auth="['user:create']">新增用户</el-button>

<!-- 按钮级 ANY 语义（用户拥有任一权限即显示） -->
<el-button v-auth.any="['user:edit', 'user:delete']">操作</el-button>

<!-- 修饰符 disabled（无权限时禁用而非移除） -->
<el-button v-auth:disabled="['user:create']">新增</el-button>

<!-- 修饰符 remove（无权限时移除 DOM） -->
```

## 5. 决策表

| 场景                 | 推荐                             |
| -------------------- | -------------------------------- |
| 搜索框输入实时请求   | `v-inputDebounce:300`            |
| 提交按钮防重复点击   | `v-buttonDebounce:500`           |
| 整页 / 整块 DOM 权限 | `v-permission`                   |
| 按钮级权限           | `v-auth`（AND/ANY 语义）         |
| 弹窗拖拽             | ProDialog 默认消费 `v-draggable` |
| 复制文本             | `v-copy`                         |

## 6. 新增自定义指令的标准流程

```bash
# 1. 在 src/directives/ 创建 xxx.d.ts + xxx.ts
# 2. 断言 install 模式 + WeakMap 单元素存储
# 3. mounted / updated / unmounted 三钩子齐全（含事件清理）
# 4. 不常见 API 加来源注释（CLAUDE.md §1.6.1）
# 5. 配套 xxx.spec.ts 单测（覆盖率 ≥ 80%）
# 6. CHANGELOG.md + 提交
```

**自动注册机制**：`src/directives/index.ts` 通过 `import.meta.glob` 扫描 `src/directives/*.ts`（排除 `*.d.ts` / `*.spec.ts` / `_*.ts` / `index.ts` 自身），`main.ts` 的 `app.use(Directives)` 一行覆盖全部。**无须手动注册**。
