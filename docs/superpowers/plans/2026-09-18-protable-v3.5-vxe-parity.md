## 关键技术细节

### 1. TreeAdapter 接口（引擎无关抽象）
```ts
interface TreeAdapter<TRow> {
  /** 树配置（传给底层表格） */
  getTreeConfig(): Record<string, unknown>
  /** 展开行 */
  expandRow(rowKey: string | number): void
  /** 收起行 */
  collapseRow(rowKey: string | number): void
  /** 获取当前展开 keys */
  getExpandedKeys(): Array<string | number>
  /** 规范化原始 data → 内部扁平 data（含 __pro_table_flat__ / children 标记） */
  normalize(rows: TRow[]): TRow[]
  /** 检测行是否有子节点 */
  hasChildren(row: TRow): boolean
}
```

### 2. vxe-table tree-config 协议
```ts
const treeConfig = {
  children: '__pro_table_flat__',
  hasChildren: '__pro_table_flat__',
  expandAll: false,
  accordion: false,
  trigger: 'default', // 单元格点击展开
}
```

### 3. sortablejs 在 vxe 行内挂载
- el-table 行 DOM: `.el-table__body-wrapper tbody tr`
- vxe-table 行 DOM: `.vxe-table--body-wrapper .vxe-body--row`

需动态检测（按引擎分支）。
