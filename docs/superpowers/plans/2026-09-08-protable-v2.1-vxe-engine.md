### P1 —— ElTable 渲染分支抽离（纯移动，行为零变化）

1. 新建 `components/ElementTableBody.vue`：承接 ProTable.vue 中 ElTable + ElTableColumn 循环整段模板（含编辑/树形/合并/拖拽手柄/插槽透传）
2. props 接口：`data` / `columns` / `rowKey` / `cellSpan` / `rowEdit` / `treeData` + 事件回调（`selection-change` / `cell-dblclick` / `expand-change` / `sort-change`）+ scoped slots 转发（`col.prop` 命名插槽、empty）
3. ProTable.vue 删除该段，改 `<ElementTableBody v-if="engineRef === 'element-plus'" ... />`
4. `resolveCell` 逻辑判断：el/vxe 两分支都需要 → 留在 ProTable.vue 经 props 传入渲染函数，或下沉到 `adapters/cell-render.ts`。实施时按「单一职责」选后者（新增小文件）
5. 验证：全量测试 + demo 手动对比（Overview / 行编辑 / 树形 / 合并 / 拖拽 5 页无视觉/行为差异）

**commit**: `refactor(pro-table): ElTable 渲染分支抽离为 ElementTableBody（v2.1 P1，行为零变化）`

### P2 —— vxe 列映射层 + 类型恢复

1. `types/index.ts` 恢复 `ProColumn.vxeProps?: Record<string, unknown>`（JSDoc：透传 VxeColumn props）

3. 新建 `adapters/vxe-column.spec.ts`：映射全字段 + 透传优先级（vxeProps 覆盖派生值与否需明确——按「vxeProps 为补充不覆盖派生」定，写进测试）
4. 验证：映射 spec 全绿

**commit**: `feat(pro-table): vxe 列映射层 + ProColumn.vxeProps 恢复（v2.1 P2）`

### P3 —— VxeTableBody 渲染分支 + 引擎解除回退

1. 新建 `components/VxeTableBody.vue`：
   - props 与 ElementTableBody 对齐；onMounted 调 `loadVxeTable()`，加载中渲染 skeleton/loading，失败 catch → emit `engine-fallback`（ProTable 收到后切回 element-plus）
   - 模板：`<VxeTable :data :sort-config="{ remote: true }" ...>` + `VxeColumn v-for`（`toVxeColumnProps`）+ default/header slot（复用 cell-render）
   - 事件：`@sort-change`（适配 payload 后 emit 统一 `SortChangeEvent`）/ `@checkbox-change` + `@checkbox-all`（合并 emit selection-change）/ `@cell-dblclick`
2. `adapters/engine.ts` 删 vxe 回退分支，`resolveEngine` 原样返回 prop；`ProTableExpose.element` JSDoc 同步（决策 6）
3. ProTable.vue：加 `VxeTableBody v-else` 分支 + fallback 处理（engineRef 是 Ref，fallback 时 `.value = 'element-plus'`）
4. 验证：类型检查 + 既有测试不回退

**commit**: `feat(pro-table): vxe-table 渲染分支 + 引擎解除回退（v2.1 P3）`
