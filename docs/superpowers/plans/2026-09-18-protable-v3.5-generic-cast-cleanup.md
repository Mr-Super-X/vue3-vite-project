## 关键技术细节

### 1. 子组件 generic 声明
```vue
<script setup lang="ts" generic="T extends object = Record<string, unknown>">
const props = defineProps<{
  columns: ProColumn<T>[]
  rows: T[]
  rowKey?: keyof T | string
  ...
}>()
</script>
```

### 2. ProTable.vue 透传类型
```vue
<SearchForm :columns="columns.searchColumns" ... />  <!-- 编译期 T 透传，无需 cast -->
```

### 3. bivariance 边界（README §163 已说明）
- TS 对具体类型用 bivariance，对泛型参数严格双向协变
- 父组件 `ProTable<User>` → 子组件 `<SearchForm<User>>` 完全类型安全
- 子组件内部若泛型与具体 cast 混合，TS 会报错

### 4. 默认 Record<string, unknown> 兜底
- 不传泛型时与现有 v3.4 行为一致
- 零迁移成本
