## 关键技术细节

### 1. filter-change 协议
```ts
// ElementTableBody 转发
@filter-change="(filters: Record<string, FilterValue[]>) => events.handleFilterChange(filters)"

// useTable 内部
filterState.value = { ...filterState.value, ...newFilters }
if (props.filterParamsAdapter) {
  const adapted = props.filterParamsAdapter(filterState.value)
  // 合并到 requestApi params
  await refresh({ filters: adapted })
}
```

### 2. 默认行为（无 adapter 时）
- 不调用服务端筛选
- filterState 仅用于 UI 状态记忆（不发给 API）
- el-table 默认客户端筛选继续生效

### 3. statePersist 集成
- useStatePersist 快照加 `filterState` 字段
- 路由返回恢复筛选状态
