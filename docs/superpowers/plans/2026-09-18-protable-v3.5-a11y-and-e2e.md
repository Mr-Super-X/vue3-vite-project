## 关键技术细节

### 1. ARIA grid 模式
参考 WAI-ARIA Authoring Practices `grid` 模式（不是 `table`）：
- `role="grid"` 在根容器
- `role="row"` 在每行
- `role="columnheader"` 在表头
- `role="gridcell"` 在单元格
- `aria-rowcount` / `aria-colcount` / `aria-rowindex` / `aria-colindex`

### 2. vitest-axe 集成
```ts
import { axe } from 'vitest-axe'
it('should have no axe violations', async () => {
  const wrapper = mount(ProTable, { ... })
  const results = await axe(wrapper.element)
  expect(results).toHaveNoViolations()
})
```

### 3. prefers-reduced-motion 测试
```ts
beforeEach(() => {
  window.matchMedia = vi.fn().mockImplementation(query => ({
    matches: query === '(prefers-reduced-motion: reduce)',
    addEventListener: vi.fn(),
    removeEventListener: vi.fn(),
  }))
})
```

## 风险与回退

| 风险 | 概率 | 回退 |
|------|------|------|
| vitest-axe 与 Vue 组件渲染时机不匹配 | 中 | 降级为手动 axe 检查脚本（`pnpm run a11y`） |
| Playwright 装包 / Chromium 下载失败 | 中 | 改用 @vitest/browser（Web 容器，但功能弱） |
| 业务方表格已有自定义列名 / 标签 | 低 | aria-label 用 ${col.label} fallback 到 ${col.prop} |
| E2E 跑通但 CI 环境无 Chrome | 中 | 加 CI 步骤 `npx playwright install --with-deps chromium` |
