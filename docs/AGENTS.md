# docs

## 用途

项目专题文档库：根级 50 篇编号文档（命名 `[序号]-中文主题.md`），覆盖工具链、架构决策、组件使用指南、适配方案、Monorepo 指引、样式分层、页面组件选型等长期有效的团队标准；根 AGENTS.md「专题文档速查」按主题索引本目录。

## 子目录

| Directory      | Purpose                                                                                                                                      |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `archive/`     | 按月归档的历史文档（如 `2026-07/`）——保留追溯，不再维护                                                                                      |
| `audit/`       | 可用性评审与引擎审查报告（带日期前缀，如 `2026-10-15-engine-audit-*.md`）                                                                    |
| `superpowers/` | superpowers 工作流产出物：`plans/`（实施计划）与 `specs/`（设计稿——改 ESLint 规则 / 架构级约定前须先在此写设计稿并等批准，项目约束第 10 条） |

## 依赖

### 内部依赖

- `scripts/check-doc-currency.ts` 对本目录做硬数据一致性校验（文档数预算冻结、关键文档与代码的数字对账），CI 阻断。
- 文档治理遵循根 AGENTS.md「治理退役准则」：docs/ 根级文档数被冻结，新增须先改预算值并在 PR 说明理由；瘦身先合并 / 归档再降预算。

### 外部依赖

- 无运行时依赖（纯 Markdown）。

## 给 AI 代理的规则

### 在本目录工作

- 新建文档命名 `[序号]-中文主题.md`，序号接续当前最大编号；复杂流程必须配 Mermaid 流程图。
- 功能性变更同步根 `CHANGELOG.md`（仅修复 typo 免记）。
- 文档中引用代码硬数据（字段数 / 文件数 / demo 数等）时，确认其已被 check-doc-currency 覆盖或避免写死易漂移数字。

### 测试要求

- 改动后运行 `pnpm check:doc-currency` 验证硬数据一致性（该门禁只锁清单内项目，清单外漂移靠人工兜底）。

### 常见模式

- 过时文档即更新或归档至 `archive/`；审查 / 调研类产出物落盘为最终态单一文档，不按轮次追加章节。
